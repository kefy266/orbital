# Dokümantasyon

1. Okuyucuyu belirle: kullanıcı mı, katkıcı mı? Ona gereken sırayla yaz.
2. README: ne işe yarar (tek cümle), kurulum, en kısa çalışan örnek, yapılandırma, katkı.
3. Komutları gerçekten çalıştırıp doğrula; çalışmayan örnek yazma.
4. Kod içi açıklamalarda "ne"yi değil "neden"i anlat; açık olanı tekrarlama.
5. Kısa cümleler, etken çatı, tutarlı terimler kullan.
